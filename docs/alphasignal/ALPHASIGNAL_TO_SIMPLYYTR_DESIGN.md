# AlphaSignal -> SIMPLYYTR Design Mapping

| AlphaSignal idea | SIMPLYYTR system |
|---|---|
| intelligence layer | opportunity intelligence layer |
| sources | trends, search, audience, product, competitor and platform signals |
| learned ranking | opportunity scoring/ranking |
| coverage | systematic source/channel/topic coverage |
| graph | opportunity/evidence/commerce graph |
| editorial selection | opportunity selection |
| contextualization | research brief + evidence graph |
| primary source first | first-party evidence preference |
| corrections | evidence/provenance correction system |
| briefs | strategy/opportunity briefs |

## Signal engine
`connectors -> raw signal -> normalized signal -> entity resolution -> dedup -> enrichment -> features -> score -> rank -> cluster -> graph`

## Initial scoring features
Recency, momentum, source diversity, corroboration, novelty, audience fit, intent, affiliate potential, production cost, risk and evidence quality.

Do not start with a black-box ranking model. Begin interpretable, then learn from outcomes.
